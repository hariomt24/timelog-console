# Contributing

Thank you for your interest in contributing to `timelog-console`.

## Project Scope

This package is intentionally small and focused. It exists only to prepend human-readable timestamps to console logs in Node.js applications.

## What We Accept

- Bug fixes
- Safety improvements
- Performance improvements
- Documentation improvements

All contributions must maintain backward compatibility.

## What Is Out of Scope

This package is not intended to become a full logging library. The following features are out of scope and will not be accepted:

- Log levels
- Colors or styling
- JSON logging
- Log transports (file, network, etc.)
- Configuration options
- Environment-based behavior
- Filtering or suppression
- Custom formatters

If you need these features, consider a dedicated logging library.

## How to Contribute

1. **Bug fixes and minor improvements**: Open a pull request with a clear description of the problem and solution.

2. **New features or changes to behavior**: Open a GitHub Issue first to discuss. Do not submit a pull request without prior discussion.

## Code Guidelines

- Keep the code simple and readable
- Avoid adding dependencies
- Preserve existing behavior
- Test your changes locally before submitting

## Questions

If you are unsure whether a contribution fits the project scope, open a GitHub Issue to ask.
